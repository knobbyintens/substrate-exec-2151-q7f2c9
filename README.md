# Substrate-Exec

Synthetic execution-quality instruction pairs used by the collective's grading
pipeline.

- `data/sample_pairs.jsonl` — six sample instruction/response pairs
- `DATASET_CARD.md` — provenance and intended use
- `CHANGELOG.md` — history of the sample file

Before external release, the dataset needs a single published license identifier
recorded in `license_decision.json` at the repository root.
